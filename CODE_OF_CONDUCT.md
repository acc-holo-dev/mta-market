# Code of Conduct

## Наши правила

Участники проекта обязуются:

- относиться к другим уважительно;
- обсуждать код и идеи конструктивно;
- не допускать оскорблений, травли, дискриминации и домогательств;
- не публиковать чужие персональные данные;
- сообщать о проблемах безопасности конфиденциально, а не через публичный issue;
- уважать лицензии и авторские права на ресурсы MTA:SA.

## Недопустимое поведение

Запрещены угрозы, преследование, спам, намеренное раскрытие персональных
данных, мошенничество, вредоносные изменения и попытки украсть или обойти
лицензионную защиту ресурсов.

## Модерация

Нарушение правил может привести к предупреждению, удалению комментариев,
закрытию issue/PR или блокировке участия в проекте. Решения принимаются
с учётом тяжести и повторяемости нарушения.

## Сообщение о нарушении

Сообщите о проблеме владельцу репозитория через приватный канал GitHub или
на email поддержки, не публикуя чувствительные подробности в открытом issue.

Правила могут обновляться по мере развития проекта.
