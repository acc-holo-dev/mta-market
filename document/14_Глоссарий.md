# 📖 Глоссарий — словарь терминов

> Ниже — термины, которые встречаются во всех документах проекта.
> Если в документе встретили непонятное слово — искать здесь.

---

## А: Проект и роли

**Мarketplace (маркетплейс)** — онлайн-площадка, где продавцы выставляют товары, покупатели их покупают. Наш проект: площадка ресурсов для MTA:SA.

**Покупатель (Buyer)** — владелец MTA-сервера, который покупает ресурсы.

**Продавец (Seller)** — скриптер, который создаёт и продаёт ресурсы. Он же часто покупатель других ресурсов.

**MVP (Minimum Viable Product)** — минимальная рабочая версия продукта: только то, без чего нельзя запуститься. Всё остальное — потом.

## Б: Технические

**Backend** — серверная часть проекта, которую не видит пользователь, но которая делает всю работу (принимает платежи, выдаёт лицензии).

**Frontend** — то, что видит пользователь в браузере: страницы, кнопки, формы.

**API** — способ, которым программы общаются между собой (Backend ↔ Frontend, DRM-модуль ↔ License Server).

**REST API** — стандарт построения API через HTTP-запросы (GET — прочитать, POST — создать, PUT — изменить, DELETE — удалить).

**Webhook** — уведомление от одной системы к другой по HTTP (например, ЮKassa присылает нам уведомление об оплате).

**JWT** — токен, который подтверждает «этот пользователь — это он». Аналог браслета на концерте: выдали на входе — носишь до конца.

**Migration (миграция)** — изменение структуры базы данных (добавить таблицу, поле), фиксируется в коде, чтобы можно было откатить.

**Monorepo (монорепозиторий)** — один репозиторий, где живёт весь проект (backend + frontend + модуль). Альтернатива: множество отдельных репозиториев.

**Docker** — способ упаковать программу с её зависимостями в контейнер, чтобы «работало везде одинаково».

## В: Лицензирование и защита (наш DRM)

**DRM (Digital Rights Management)** — система защиты цифровых продуктов от копирования и нелегального использования. Наш случай: шифрование + лицензии + HWID.

**Лицензия** — право пользоваться скриптом на одном сервере. Может быть: разовая (навсегда) или подпиской (на месяц).

**HWID (Hardware ID)** — уникальный «отпечаток» железа сервера (MAC-адрес + серийный номер диска + CPU). К нему привязывается лицензия, чтобы скрипт работал только на конкретном сервере.

**DEK (Data Encryption Key)** — ключ, которым зашифрован сам скрипт. Хранится только в зашифрованном виде, к расшифровке допускается только модуль DRM.

**Heartbeat** — периодический «пульс»: DRM-модуль проверяет активность лицензии на License Server каждые 30 минут.

**Grace period (грейс-период)** — 48 часов, когда скрипт работает без связи с площадкой (например, сеть легла, но играть можно). Через 48ч — модуль отключает скрипт.

**Ed25519** — современный алгоритм цифровой подписи. Используется, чтобы модуль мог проверить: «ответ действительно от License Server, подделать нельзя».

**AES-256-GCM** — симметричный алгоритм шифрования. Наш выбор для шифрования файлов скриптов.

**Watermark (водяной знак)** — невидимая метка в каждой проданной копии скрипта, чтобы найти источник утечки.

**Леак (Leak)** — утечка, слив скрипта в публичный доступ.

## Г: Платежи

**Escrow (гарант)** — деньги покупателя замораживаются на счету площадки до тех пор, пока покупатель не подтвердит покупку. Только после подтверждения продавец получает оплату.

**ЮKassa** — платёжный агрегатор, через который мы принимаем платежи (карты, СБП и т.д.).

**Webhook платежа** — уведомление от ЮKassa о статусе платежа: успех, отмена, возврат.

**Test mode (test\_ ключи)** — тестовый режим ЮKassa: платежи проходят, деньги не настоящие.

**Рекуррентный платёж** — автоматическое регулярное списание (ежемесячная подписка).

**Idempotency-Key** — уникальный ключ операции, защищает от двойной оплаты (если пользователь дважды нажал «Оплатить»).

**ГMV (GMV)** — Gross Merchandise Value, общая сумма всех продаж на площадке за месяц. Главный индикатор здоровья.

**Комиссия площадки** — 15% с каждой продажи, удерживается при подтверждении escrow.

## Д: База данных и инфраструктура

**PostgreSQL** — наша основная база данных, где хранится всё: пользователи, лицензии, покупки.

**Redis** — быстрая база данных в памяти (для кэша и сессий), не для постоянных данных.

**S3 / MinIO** — хранилище файлов (самих скриптов, картинок).

**VDS/VPS** — виртуальный сервер, который вы арендуете ($15-25 в месяц).

**Nginx** — «швейцарский нож» веб-сервера: раздаёт Frontend, принимает API-запросы.

**Deploy (деплой)** — перенос свежей версии проекта на боевой сервер.

**Backup (бэкап)** — резервная копия базы данных. Без него проект — карточный домик.

**Docker Compose** — файл, который говорит: «подними мне PostgreSQL + Redis + MinIO одной командой».

## Е: Моделирование и работа с кодом

**ADR (Architecture Decision Record)** — запись о важном решении: контекст → выбор → последствия. Смотри 13_Решения.md.

**CI (Continuous Integration)** — автоматическая проверка при каждом push: не сломали ли изменения.

**Backend-модуль** — папка с кодом, отвечающая за одну сущность (auth, licenses, payments). Внутри модуля — всё про него, чтобы не запутаться.

**Rate limit** — ограничение количества запросов (защита от ботов и взлома).

**Unit / Integration / E2E тесты** — уровни тестов: отдельная функция / проверка API / полное поведение как пользователь.

**Smoke-тест** — быстрая проверка «работает ли вообще» после изменений.
