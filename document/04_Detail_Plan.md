## Часть A. Аутентификация и пользователи (модуль `auth/`)

**Что делает:** регистрация, вход, роли, безопасность аккаунтов.

| Элемент | Как реализуем | Статус |
|---|---|---|
| Регистрация | email + пароль (argon2id хэш) | ⬜ |
| Верификация email | отправка ссылки, одноразовый токен (TTL 24ч) | ⬜ |
| Вход | JWT-токен (access 15 мин + refresh 30 дней) | ⬜ |
| OAuth (Discord/Google) | быстрый вход по кнопке | ⬜ |
| Сброс пароля | одноразовая ссылка (TTL 1 час) | ⬜ |
| Роли | user / seller / admin через поля в БД | ⬜ |

**Дизайн страниц:** форма входа, форма регистрации, страница «проверьте почту».

## Часть B. Каталог ресурсов (модуль `catalog/` + `resources/`)

**Что делает:** витрина товаров, поиск, карточка товара.

| Элемент | Как реализуем | Статус |
|---|---|---|
| Список товаров | React Query + пагинация (12/стр) | ⬜ |
| Поиск | PostgreSQL FTS (позже Meilisearch) | ⬜ |
| Категории и теги | таблица + выпадающий список | ⬜ |
| Карточка товара | Markdown-описание, галерея, цена, купить | ⬜ |
| Загрузка (продавец) | upload blob → шифрование → preview | ⬜ |
| Тест-драйв (live demo) | Фаза 2 | ⬜ |

## Часть C. Платежи и подписки (модуль `payments/`)

**Что делает:** оплата, подписки, возвраты, комиссия. Детально в `06_Платежка.md`.

| Элемент | Как реализуем | Статус |
|---|---|---|
| ЮKassa подключение | см. 06_Платежка.md | ⬜ |
| Покупка | webhook `payment.succeeded` → выдача лицензии | ⬜ |
| Подписка (продление) | рекуррентные платежи через ЮKassa | ⬜ |
| Возвраты | через админ-панель, вручную | ⬜ |
| Комиссия площадки | 15% автоматом при подтверждении escrow | ⬜ |
| Escrow (гарант) | статус заказа → подтверждение → release | ⬜ |

---

## Часть D. Лицензирование и DRM (модуль `licenses/` + `packages/drm-module/`) ⭐

**Что делает:** сердце системы. См. `09_Спецификация_DRM.md` (когда будет).

| Элемент | Как реализуем | Статус |
|---|---|---|
| HWID сбор | C++: MAC + volume serial + CPU hash | ⬜ |
| Heartbeat | модуль → API раз в 30 мин, если невозможно — grace 48ч | ⬜ |
| Расшифровка скриптов | AES-256-GCM, ключ в памяти после verify | ⬜ |
| Отзыв | админ-панель → heartbeat видит revoke → отключает | ⬜ |
| Замена HWID | через личный кабинет, лимит N в месяц | ⬜ |
| Watermark | уникальный ID продажи внутри сборки | ⬜ |
