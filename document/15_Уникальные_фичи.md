# 💎 Уникальные фичи и источники вдохновения

> Полный список фич, которые отличают MTA Market от всего существующего
> в MTA-мире, с техническими источниками и ссылками. Этот документ —
> «золотой список» продукта: всё, что делает площадку уникальной.

## 1. Флагманские фичи (нет ни у кого в MTA-мире)

### 1.1 Live-Demo: «попробуй до покупки» ★ главная фича

У площадки есть собственный публичный MTA-сервер. Покупатель жмёт
«Тест-драйв» на карточке → сервер поднимает ресурс в демо-режиме →
покупатель подключается MTA-клиентом и трогает скрипт руками 15 минут.

- **Почему:** оценивать скрипты по видео — как покупать машину по фото.
  Live-demo решает главный барьер покупки «а вдруг не подойдёт».
- **Реализация:** headless MTA-серверы в Docker, слот-пул, авторизация
  разовым кодом с сайта. Демо-режим = лицензия с TTL 15 мин, скрипт
  печатает в чат «DEMO» — снять скриншот можно, унести продукт нельзя.
- **Витрина:** бейдж на карточке «🟢 доступен тест-драйв».

### 1.2 Asset Studio: 3D-просмотр моделей в браузере
*(идея родилась от официального инструмента MTA — см. источники)*

На площадке продаются не только скрипты, но и модели (авто, скины,
объекты). Их продают по скриншотам — как машину по фото. Решение:

- **Интерактивный 3D-вьюер прямо в карточке товара** (вращение, зум,
  смена текстур, цветовые варианты): DFF/TXD парсятся **в браузере**,
  рендер на Three.js.
- **Автогенерация превью:** продавец загружает DFF+TXD → сервер
  (headless) сам рендерит постер + turntable-GIF 360° для карточки.
  Продавцу не нужно снимать скриншоты.
- **Валидация ассетов:** интеграция подхода rwtool (официальный
  RenderWare asset inspector) — проверка целостности DFF/TXD при
  загрузке → бейдж «✅ validated asset».
- **Автостатистика в карточке:** полигоны, количество текстур, их
  разрешение, наличие LOD/коллизии — честные метрики качества модели.
- **Просмотр карт (.map):** .map — это XML → мини-карта прямо в карточке.
- **Слайдер «до/после»** для реплейсеров (HD-текстуры, замена моделей).
- **Скин-вьюер с анимациями:** для моделей персонажей — проигрывание
  walk/run/idle прямо в браузере.
- **Кастомные колорвэи:** продавец загружает варианты расцветок —
  покупатель крутит 3D и выбирает цвет до покупки (киллер-фича для авто).

**⚠️ Важная оговорка по DRM:** модели защитить шифрованием нельзя
(движок MTA должен читать DFF/TXD открыто, в отличие от Lua-скриптов).
Защита для моделей = водяные знаки в текстурах + Leak Radar (п. 1.4).
3D-вьюер отдаёт превью со сжатием/анонимизацией, не оригинальные файлы.

**Источники и техническая база (реальные, проверенные):**

| Источник | Что это | Ссылка |
|---|---|---|
| rwtool | Официальный RenderWare asset inspector MTA — целиком работает в браузере, парсит и чинит DFF/TXD локально. Родоначальник идеи | https://nightly.mtasa.com/rwtool/ |
| rw-parser | npm-пакет: парсит DFF/TXD в удобный формат (актуально поддерживается) | https://www.npmjs.com/package/rw-parser |

### 1.3 One-Module-For-All: единый модуль площадки

Покупателю не нужен модуль на каждый скрипт. **Один .dll/.so** от
площадки управляет ВСЕМИ купленными ресурсами:

```
install: mta-market.dll → одна строка в mtaserver.conf
в игре: один модуль = все лицензии, авто-обновления, совместимость
```

- Скрипты устанавливаются копированием зашифрованного blob в resources/ +
  одна строка в meta.xml (или полностью авто через модуль);
- Обновления: модуль качает новую версию и подписывает её сам;
  покупателю не нужно ничего делать вручную.

### 1.4 Watermark + Leak Radar («найдёт и накажет»)

- Каждая проданная копия содержит невидимый водяной знак: уникальный ID
  сборки (в коде + в шифрованном blob + микровариации в логике).
- Краулер мониторит VK/Telegram/GitHub/форумы на слив.
- Найден leaked-хэш → в админ-панели автоматически: кто купил, когда,
  какой HWID стоял.
- Кнопка «Report leak» для сообщества (с премией репортёру на баланс).

### 1.5 Пассивный аудит совместимости

Heartbeat присылает версию MTA-сервера, список ресурсов, версию ОС.
В карточке ресурса: «✅ протестирован на MTA 1.6.0, Ubuntu 22, Windows».
Когда выходит новый MTA — авто-прогон по всем платным ресурсам на
CI-ферме → продавцам прилетает «ваш ресурс сломался / ок» → бейдж
актуальности совместимости.

### 1.6 Здоровье лицензии как витринный аргумент

На карточке — публичная статистика «живых» лицензий (сколько активных
серверов используют прямо сейчас, heartbeat за 24ч). Соцдоказательство,
которое нельзя подделать, т.к. данные из License Server.

### 1.7 Селлер-аналитика уровня ecommerce

Продавец в кабинете видит: просмотры → конверсия, из каких источников,
на каких серверах (анонимно) крутится его скрипт, гео, повторные
покупки, доход по месяцам. Всё берётся из heartbeat-телеметрии — данные,
которые продавцы «в личке» никогда не видели.

### 1.8 Депозит доверия

Продавец может заморозить часть своих будущих выплат в «депозит гаранта»:
в карточке горит «депозит 5 000 ₽ — гарантия возврата». При обмане —
выплата покупателю из депозита. Мошенникам невыгодно, честным — рейтинг.

## 2. Приятные фичи UX

### Покупателю
- Dark/Light + MTA-стилистика в дизайне (знакомые игрокам цвета);
- Сравнение ресурсов рядом (diff-таблицей);
- «Мой сервер»: покупатель указывает свой сервер → фильтры каталога
  сразу скрывают несовместимые ресурсы;
- История версий с changelog как в GitHub releases;
- Уведомление «вышло обновление купленного» → one-click update;
- Шаблонные пакеты для новичков: «Открой DM-сервер» → bundle из 12
  ресурсов со скидкой 30%.

### Продавцу
- Upload wizard с проверками (структура meta.xml, размер, зависимости)
  ещё ДО загрузки — мгновенная валидация в браузере;
- Планировщик релизов (draft → release datetime);
- A/B карточки товара (2 заголовка/обложки → статистика кликов);
- Промокоды по ссылке для ютуберов (инфлюенсер-программа);
- REST API + webhooks для продавцов (интеграция с их Discord).

### Общие
- Поиск с опечатками (Meilisearch), фильтры сохраняются в URL;
- 2FA для продавцов, сессии с историей входов;
- Экспорт своих продаж в CSV;
- Страница /status — публичный статус всех систем (uptime License
  Server критичен, доверие к нему должно быть видимым).

## 3. Чего НЕ делать (антифичи)

- ❌ Собственный форум (Discord-сообщества уже есть, не конкурировать);
- ❌ Скачивание открытых исходников платных скриптов;
- ❌ Мобильное приложение (адаптивного сайта хватит на годы);
- ❌ Ручная модерация каждого отзыва — автофильтры + жалобы;
- ❌ Собственный видео-хостинг — только embed YouTube;
- ❌ Сложная система уровней/ачивок продавцам на старте.
